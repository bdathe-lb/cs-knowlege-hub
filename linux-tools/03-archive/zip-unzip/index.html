zip & unzip

简介

Section titled “简介”

zip 和 unzip 是 Linux 系统中用于创建和解压 .zip 格式压缩文件的工具，使用 Deflate 算法（默认），支持多文件压缩、保留目录结构、加密压缩，并且跨平台兼容（Windows、macOS、Linux）。

基本语法

Section titled “基本语法”

zip（压缩）

  • zip 只用于压缩，解压通常使用 unzip 命令
  • zip 可以一次压缩多个文件或目录，如果需要压缩整个目录，需要加 -r（递归）选项
  • zip 默认是创建或更新压缩包，如果指定的压缩包已经存在，它会自动把指定文件添加或更新到压缩包中

unzip（解压）

  • 不指定文件则解压压缩包中所有文件
  • 指定文件则只解压压缩包中的部分文件

常用选项

Section titled “常用选项”

zip 选项

Section titled “zip 选项”

1. 基础压缩选项

选项 说明
-r 递归压缩目录（包括子目录）
-0 至 -9 设置压缩级别（-0 无压缩，-9 最高压缩率，默认 -6）
-q 安静模式（不显示压缩过程的详细信息）
-v 详细模式（显示压缩进度、文件信息、压缩率等）

2. 高级功能选项

选项 说明
-u <files> 更新已有文件或添加新文件，但不影响压缩包里其他文件
-d <files> 从压缩包中删除指定文件
-e 加密压缩包（会提示输入密码，解压时需输入密码）
-j 仅压缩文件内容，不保留目录结构（所有文件直接放在压缩包根目录）

unzip 选项

Section titled “unzip 选项”

1. 基础解压选项

选项 说明
-d <dir> 指定解压目标目录（默认解压到当前目录）
-l 仅列出压缩包中的文件列表，不解压
-t 测试压缩包的完整性（检查是否有损坏或错误）
-v 详细模式（显示解压进度、文件权限、压缩率等信息）
-q 安静模式（不显示解压过程的详细信息）

2. 高级操作选项

选项 说明
-o 覆盖模式（解压时直接覆盖已存在的文件，不提示）
-n 不覆盖模式（不解压已存在的文件，避免覆盖）
-j 解压时忽略原目录结构，将所有文件提取到同一目录
-x <files> 排除指定文件（解压时不提取该文件）
