lsblk

简介

Section titled “简介”

lsblk 是 Linux 系统中用于列出块设备信息的实用工具，能以树形结构展示系统中所有的磁盘、分区及其他块设备，帮助用户快速了解存储设备的布局和关系。

基本语法

Section titled “基本语法”
  • 若不指定设备名，lsblk 会列出所有可见的块设备
  • 若指定设备名（如 /dev/sda），则仅显示该设备的信息

设备名只能是设备节点路径，不能是 UUID。

默认输出包含以下关键列：

列名 说明
NAME 设备名称（如 sda、sda1）
MAJ:MIN 主设备号和次设备号
RM 是否为可移动设备（1 表示可移动，0 表示固定）
SIZE 设备大小
RO 是否为只读设备（1 表示只读，0 表示可写）
TYPE 设备类型（disk 表示磁盘，part 表示分区，loop 表示 iso 等）
MOUNTPOINT 设备的挂载点（若已挂载）

常用选项

Section titled “常用选项”
选项 说明 示例
-a 显示所有块设备（包括空设备） lsblk -a
-b 以字节为单位显示设备大小 lsblk -b
-d 仅显示磁盘设备，不显示分区 lsblk -d
-e <主设备号> 排除指定类型的设备 lsblk -e 1,7
-f 显示文件系统信息（类型、UUID、挂载点等） lsblk -f
-l 以精简列表形式显示（不换行） lsblk -l
-n 不显示标题行 lsblk -n
-o 自定义输出列 lsblk -o NAME,SIZE,TYPE
-p 显示设备的完整路径（如 /dev/sda 而非 sda） lsblk -p
