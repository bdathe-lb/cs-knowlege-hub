Vim

简介

Section titled “简介”

Vim 是一个高效的模态文本编辑器，通过区分不同的编辑模式，实现快速的文本操作，避免频繁使用鼠标和方向键。

参数 说明
文件名 要编辑的文件

Vim 哲学

Section titled “Vim 哲学”

Vim 采用模式编辑的理念，按键在不同模式下有不同的作用：

  • 普通模式：用于浏览文件，执行各种命令，如 dd、yy、p、u
  • 插入模式：用于输入文本，像普通编辑器一样打字
  • 替换模式：类似插入模式，但新字符会替换旧字符（逐个替换）
  • 可视模式：用于选择一段文本以进行操作（删除、复制、缩进等）
  • 命令模式：用于执行冒号命令，如 :w 保存、:s 查找替换等

缓冲区、窗口、标签页

Section titled “缓冲区、窗口、标签页”

缓冲区（Buffer）

Section titled “缓冲区（Buffer）”
  • 定义：当在 Vim 中打开一个文件时，Vim 就会为它在内存中创建一个缓冲区，并将文件从磁盘中读取到缓冲区中。Vim 的操作实际是在操作缓冲区，保存时才写回磁盘。
  • 特点：
    • 每个文件对应一个缓冲区
    • 即使缓冲区没有在窗口中显示，它依然存在于内存中
  • 相关命令：
    • :ls 或 :buffers：列出所有缓冲区
    • :b <num>：跳转到编号为 <num> 的缓冲区
    • :bd：删除当前的缓冲区
    • :bn / :bp：切换下一个 / 上一个缓冲区

窗口（Window）

Section titled “窗口（Window）”
  • 定义：Vim 的窗口是对缓冲区内容的一个“视图”，可以理解为“查看缓冲区的窗口”。在一个 Vim 实例中可以打开多个窗口，每个窗口可以显示同一个或不同的缓冲区。
  • 特点：
    • 一个窗口只能显示一个缓冲区，但一个缓冲区可以被多个窗口同时显示
    • 窗口可以被分割（水平 / 垂直），形成多个子窗口
  • 相关命令：
    • :split（或 :sp）：水平分割窗口
    • :vsplit（或 :vsp）：垂直分割窗口
    • <Ctrl-w> h/j/k/l：在窗口之间切换
    • :close：关闭当前窗口
    • :only：关闭其他窗口，只保留当前

标签页（Tab Page）

Section titled “标签页（Tab Page）”
  • 定义：标签页是窗口的集合。每个标签页可以包含一个或多个窗口，它们的布局是独立的，可以理解为“一组窗口的容器”。
  • 特点：
    • 每个标签页可以包含多个窗口，切换标签页时会整体切换窗口布局
    • 不同标签页之间互不干扰，可以作为“工作区”使用
  • 相关命令：
    • :tabnew：新建一个标签页
    • :tabs：列出所有标签页
    • :tabnext 或 gt：切换到下一个标签页
    • :tabprev 或 gT：切换到上一个标签页
    • :tabclose：关闭当前标签页

三者关系

Section titled “三者关系”
  • 一个标签页中可以有多个窗口
  • 一个窗口中显示一个缓冲区
  • 一个缓冲区可以在多个窗口中同时显示

寄存器

Section titled “寄存器”

寄存器就是 Vim 里的“剪贴板”，可以存放文本（复制、剪切、宏录制等内容），Vim 有多个寄存器，支持多份内容同时存储。

常用寄存器

Section titled “常用寄存器”
寄存器名 含义与用途 使用示例
"" 默认寄存器，存放最近一次 yank 或 delete p 粘贴默认寄存器内容
"0 yank 寄存器，只存放最近一次 yank（复制） "0p 粘贴最后复制内容
"+ 系统剪贴板寄存器（需要支持） "+y 复制到系统剪贴板
"- 黑洞寄存器，删除但不保存内容，避免污染其他寄存器 "_d 删除但不存寄存器
"1–"9 编号寄存器，存放删除操作的历史 "1p 粘贴最近删除的内容
"a–"z 命名寄存器，可手动存储和调用文本 "ayy 复制到寄存器 a

Motion

Section titled “Motion”

Motion 可以进行光标移动，其核心作用是在文本中指定一个范围，配合操作符（如 d、c、y 等）来操作这段文本。常用 motion：

命令 用途
h 光标向左移动一个字符
j 光标向下移动一个字符
k 光标向上移动一个字符
l 光标向右移动一个字符
0 光标移动到该行的行首，相当于 <Home>
$ 光标移动到该行的末尾，相当于 <End>
w 光标移动到下一个单词的开头
e 光标移动到当前/下一个单词的结尾
b 光标移动到前一个单词的开头
ge 光标移动到前一个单词的结尾
G 光标移动到文件的最后一行
gg 光标移动到文件的第一行
% 光标移动到匹配的括号
{ 移动到上一个段落开头
} 移动到下一个段落开头

其他移动指令：

命令 用途
<num> h/j/k/l 光标向左/下/上/右移动 num 行
<num><Enter> 光标向下移动 num 行
<num>G 光标移动到文件的第 <num> 行

删除、复制、变更

Section titled “删除、复制、变更”

Vim 中对文件进行删除、复制、变更等操作有一个统一的格式：

  • operator：表示要对选定文本执行的操作
    • d – 删除（delete）
    • y – 复制（yank）
    • c – 更改（change）
    • > – 右缩进
    • < – 左缩进
    • = – 自动缩进
  • number：可选的数字，表示重复操作的次数
  • motion：表示操作范围的移动方式

注意：2dw 和 d2w 效果相同，Vim 会把数字自动识别为作用于 motion 的重复。

替换

Section titled “替换”

基本替换语法：

  • [范围]：指定替换所作用的范围，缺省默认当前行
    • % 表示整个文件
    • . 表示当前行
    • <n1>,<n2> 表示第 n1 行到第 n2 行
    • '<,'> 表示选区（进入可视模式后 Vim 会自动填入）
  • s：substitute
  • [标志]：控制其他行为
    • g：global，贪婪模式，替换范围内所有匹配项
    • c：confirm，每次替换前询问
    • i：ignorecase，本次替换忽略大小写
    • n：no-substitute，只查找匹配数，不进行真正替换

常用替换命令：

替换命令 说明
:s/foo/bar/ 当前行第一次出现的 foo 替换为 bar
:s/foo/bar/g 当前行所有 foo 替换为 bar
:s/foo/bar/gc 替换时每次都询问是否确认
:%s/foo/bar/g 替换整个文件中的所有 foo 为 bar
:3,10s/foo/bar/g 替换第 3 到第 10 行之间的内容
:'<,'>s/foo/bar/g 替换当前选中的可视区域
