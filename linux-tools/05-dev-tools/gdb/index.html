GDB

简介

Section titled “简介”

GDB（GNU Debugger）是一个命令行调试工具，可用于调试使用各种编程语言编写的程序。它允许在被调试的代码中检查内存、控制代码的执行状态、检测代码特定部分的执行等。

基本语法

Section titled “基本语法”
参数 说明
可执行文件 需要调试的程序
core 文件 程序崩溃时生成的 core dump

Section titled “常用命令”

启动命令

Section titled “启动命令”
命令 说明
gdb ./prog 启动时加载程序
gdb ./prog core 调试崩溃程序（core dump）
gdb -tui ./prog TUI 模式（图形化界面）

TUI 模式下程序输出可能导致界面错乱，可通过 refresh 手动刷新。

layout 命令可在终端中创建多窗口布局：

  • layout src：显示源代码窗口和命令行窗口
  • layout asm：显示汇编代码窗口和命令行窗口
  • layout split：上下分屏显示源代码和汇编代码
  • layout regs：在代码窗口下方显示寄存器窗口

运行控制

Section titled “运行控制”
命令 说明
run / r 启动程序（可带参数）
continue / c 继续运行直到下一个断点
step / s 单步进入函数（会进入被调用函数内部）
next / n 单步执行但不进入函数内部
finish 直接运行到当前函数结束（快速跳出函数）

内存操作

Section titled “内存操作”

x/[n][f][u] address：检查内存

  • n：显示的单元数（可选，默认 1）
  • f：输出格式（x 十六进制、d 十进制、s 字符串、i 指令）
  • u：单元大小（b 字节、h 半字 2 字节、w 字 4 字节、g 双字 8 字节）
  • address：内存地址（变量名、指针值、表达式等）

set {TYPE}<address> = <value>：直接修改内存
