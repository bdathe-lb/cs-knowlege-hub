which

简介

Section titled “简介”

which 用于在 $PATH 里查找可执行文件的位置，回答「我敲下这个命令，实际跑起来的是哪个文件」。

基本语法

Section titled “基本语法”

按 $PATH 里的目录顺序查找，第一个命中的就是实际会被执行的那个 找不到时没有输出，返回非零

工作原理

Section titled “工作原理”

shell 解析一个命令名的顺序是：别名 → 函数 → 内建命令 → $PATH 里的可执行文件。which 只看最后一层，前三层它一概不知道。

所以 which cd 什么都查不到 —— cd 是 shell 内建命令，磁盘上根本没有这个文件，见 cd。同理，自己定义的别名和函数 which 也看不见。

常用选项

Section titled “常用选项”
选项 说明
-a 列出 $PATH 里所有同名的可执行文件，不止第一个
--skip-dot 跳过 $PATH 里以 . 开头的目录
--skip-tilde 跳过用户家目录下的路径
--read-alias 读取别名（需要 shell 把别名传进来，多数发行版默认不生效）

which 有好几个不同的实现（debianutils、GNU、以及 shell 内建版），选项支持并不一致 只有 -a 是各家都有的
