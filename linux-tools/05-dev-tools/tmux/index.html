tmux

简介

Section titled “简介”

tmux 是一个终端多路复用器（terminal multiplexer），它允许用户在一个终端窗口中运行多个终端会话，并通过分割窗口、创建标签页等方式高效管理这些会话。

基本语法

Section titled “基本语法”

tmux 提供三个核心概念：

  • 会话（Session）：一个独立的工作环境，可以包含多个窗口，每个会话有唯一的名称或编号
  • 窗口（Window）：类似于浏览器中的标签页，一个会话可以包含多个窗口，每个窗口占据整个终端区域
  • 面板（Pane）：一个窗口可以分割为多个面板，每个面板运行一个独立的终端实例

前缀键

Section titled “前缀键”

前缀键是 tmux 的特殊快捷键，必须在执行大多数 tmux 快捷键之前按下，用于区分普通终端输入和 tmux 的控制命令。

默认前缀键是 Ctrl+b，即先按下 Ctrl+b，再按对应的快捷键。 例如帮助命令的快捷键是 Ctrl+b ?：先按 Ctrl+b，再按 ?，即可显示帮助信息。

快捷键速查

Section titled “快捷键速查”

以下快捷键均需先按前缀键（默认 Ctrl+b）。

会话管理

功能 对应命令行 快捷键
新建会话 tmux new -s <session-name> 无
分离当前会话 tmux detach d / D
显示会话列表并切换 tmux list-sessions / tmux attach -t session_name s
重命名当前会话 tmux rename-session new_name $
切换到上一个会话 tmux previous-session (
切换到下一个会话 tmux next-session )
杀死指定会话 tmux kill-session -t session_name 无

窗口管理

功能 对应命令行 快捷键
创建新窗口 tmux new-window c
切换到下一个窗口 tmux next-window n
切换到上一个窗口 tmux previous-window p
切换到指定编号窗口 tmux select-window -t window_index 0-9
显示窗口列表并切换 tmux list-windows w
重命名当前窗口 tmux rename-window new_name ,
关闭当前窗口 tmux kill-window &
与上一个窗口交换位置 tmux swap-window -t -1 {
与下一个窗口交换位置 tmux swap-window -t +1 }
查找窗口 tmux find-window pattern f
移动窗口到指定编号 tmux move-window -t target_index 无

面板管理

功能 对应命令行 快捷键
水平分割面板 tmux split-window -h %
垂直分割面板 tmux split-window -v "
切换到指定方向面板 tmux select-pane -L/-R/-U/-D 方向键
显示面板编号并切换 tmux display-panes q
关闭当前面板 tmux kill-pane x
最大化/恢复当前面板 tmux resize-pane -Z z
调整面板大小 tmux resize-pane -L/-R/-U/-D amount Ctrl+方向键
垂直均分布局 tmux select-layout even-horizontal Alt+1
水平均分布局 tmux select-layout even-vertical Alt+2
主面板水平布局 tmux select-layout main-horizontal Alt+3
主面板垂直布局 tmux select-layout main-vertical Alt+4
平铺布局 tmux select-layout tiled Alt+5
将面板转换为窗口 tmux break-pane Ctrl-b !

辅助快捷键

快捷键 功能 说明
Ctrl-b : 进入命令模式 打开命令提示符，输入 tmux 命令（如 split-window、set-option）
Ctrl-b ? 显示帮助（快捷键列表） 查看所有可用快捷键，进入复制模式浏览

配置 tmux

Section titled “配置 tmux”

tmux 的配置通过 ~/.tmux.conf 文件管理，配置文件会在 tmux 启动时加载。文件内容就是 tmux 命令。若想在已开启的会话中重新加载配置，可用 tmux source-file ~/.tmux.conf。
