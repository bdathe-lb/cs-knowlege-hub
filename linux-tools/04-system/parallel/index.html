GNU Parallel

简介

Section titled “简介”

GNU Parallel 是一个用于并行执行 Shell 命令的工具，能够利用 CPU 的多核特性，将原本需要串行执行的任务并行化处理，从而极大地提高执行效率。特别适用于批量文件处理、大规模数据转换、网络请求以及计算密集型任务。

基本语法

Section titled “基本语法”
  • 选项：控制并发数、日志、远程执行等行为
  • command：要运行的命令模板
  • :::：分隔符，后面紧跟参数列表（类似于标准输入）
  • {}：占位符，会被替换为具体的参数

如果命令中没有包含 {}，Parallel 默认会在命令末尾追加参数，建议显式写出 {} 以增加可读性。

工作原理

Section titled “工作原理”

Parallel 的核心在于任务调度与输出缓冲，它不是简单地后台运行命令，而是作为一个作业管理器存在。

整体流程

Section titled “整体流程”

Parallel 的工作过程可以分为三个阶段：

step1 输入解析与分发

  • 读取标准输入（Stdin）或命令行参数（:::）
  • 根据指定的并发数（-j）建立作业队列

step2 并行执行

  • 启动子进程：根据 CPU 核心数或用户设定，同时运行多个命令实例
  • 替换参数：将输入行动态填充到命令模板中的 {} 位置

step3 输出聚合

  • 缓冲输出：Parallel 会捕获每个作业的标准输出（stdout）和错误输出（stderr）
  • 原子打印：只有当一个作业彻底完成后，才将其输出一次性打印到屏幕，保证多线程环境下输出不会乱序交织

内部机制

Section titled “内部机制”

(1) 智能核心利用

默认情况下，Parallel 会检测当前机器的 CPU 物理核心数，并以此作为并发度。

(2) 替换字符串

类似于 awk 的 $1，Parallel 使用 {} 及其变体来代表当前的输入参数。

(3) 输出保序（可选）

  • 默认情况下，谁先做完谁先输出
  • 使用 -k 时，Parallel 会暂存先完成的任务结果，强制按输入顺序输出

Section titled “替换字符串”

符号 含义 对应示例值
{} 完整输入行 data/archive.tar.gz
{.} 去掉扩展名 data/archive.tar
{/} 基名 archive.tar.gz
{//} 目录名 data

{#} 作业序列号 1（如果是第一个任务）

控制选项

Section titled “控制选项”
选项 含义与作用
-j N 并发数；N 可以是数字或百分比（如 100%），默认是 CPU 核心数
-k 保持顺序（Keep Order）；强制输出顺序与输入顺序一致
--dry-run 空运行；只打印将要执行的命令，不实际运行
--bar 显示进度条；显示完成度、速度和预计剩余时间
--joblog file 记录日志；将每个任务的退出码、运行时间记录到文件
--resume 断点续传；配合 --joblog 使用，跳过已成功的任务
--pipe 分块处理；将输入（通常是大文件）分块后传给命令
-S host 远程执行（SSH）；在远程服务器上运行命令
