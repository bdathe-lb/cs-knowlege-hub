touch

简介

Section titled “简介”

touch 的本职是修改文件的时间戳，文件不存在时顺带创建一个空文件 —— 后面这个副作用反倒成了它最常见的用途。

基本语法

Section titled “基本语法”

不带选项时把 atime 和 mtime 都设成当前时间 文件已存在不会清空内容，只动时间戳；要清空用 > file

工作原理

Section titled “工作原理”

文件的元数据里记着三个时间戳，touch 能改的只是其中两个：

时间戳 含义 查看
atime 最后一次读取内容的时间（access） ls -lu、stat
mtime 最后一次修改内容的时间（modify） ls -l、stat
ctime inode 最后一次变动的时间（change），权限、属主、链接数变了都算 ls -lc、stat

touch 能改 atime 和 mtime，改不了 ctime 恰恰相反，任何一次 touch 都会把 ctime 刷成当前时间 —— 改时间戳本身就是一次 inode 变动

常用选项

Section titled “常用选项”
选项 说明
-a 只改 atime
-m 只改 mtime
-c 文件不存在时不要创建（no-create）
-d <时间> 用可读的时间字符串，如 "2024-01-01 08:00"、"-2 days"
-t <时间> 用 [[CC]YY]MMDDhhmm[.ss] 格式，如 202401010800
-r <文件> 把时间戳对齐到另一个文件（reference）
-h 目标是软链接时改链接自身，不跟随到目标文件

使用示例

Section titled “使用示例”

1. 创建空文件

花括号由 shell 展开，见 glob

2. 指定时间

-d 接受相对时间，-t 只认固定格式的数字串

3. 对齐到另一个文件

常用于让一批文件的时间戳保持一致

4. 只刷时间，不创建

脚本里刷新已有文件的时间戳时加上 -c，避免路径写错造出一堆空文件

5. 强制重新编译

make 靠比较源文件和目标文件的 mtime 决定要不要重建，touch 一下源文件就能强制触发一次，见 make
