du

简介

Section titled “简介”

du（disk usage）用于显示文件或目录的磁盘空间使用情况，会递归统计目录下所有文件的大小并显示。

基本语法

Section titled “基本语法”
  • 如果不指定文件或目录，默认统计当前目录及其子目录
  • 输出通常以**块（block）**为单位，块的大小默认为 1K

常用选项

Section titled “常用选项”
选项 作用
-h 以人类可读的方式显示大小（自动转换为 KB、MB、GB 等）
-s 只显示指定文件或目录的总大小，不列出子文件/子目录的详细大小
-a 显示所有文件和目录的大小（默认只显示目录的大小，不单独列出文件）
-c 显示所有指定文件或目录的大小之和
-d <N> 显示指定深度的目录大小（N 是层级深度）
--max-depth=N 与 -d 类似，限制输出的目录层级，N=0 时等价于 -s
-k 以 KB 为单位显示大小
-m 以 MB 为单位显示大小
--time 显示文件或目录的最后修改时间
--exclude=PATTERN 排除匹配 PATTERN 的文件或目录
