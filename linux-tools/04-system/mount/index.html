mount & umount

简介

Section titled “简介”

mount 和 umount 是 Linux 系统中用于挂载和卸载文件系统的核心工具。挂载是将存储设备（如硬盘分区、U 盘、光盘、网络共享等）连接到文件树中某个目录（挂载点）的过程，只有经过挂载，用户才能通过该目录访问设备中的数据。

  • 未挂载的设备无法直接访问，仅作为块设备文件存在于 /dev 目录下（如 /dev/sda1）
  • 挂载点必须是一个已存在的空目录（若目录非空，挂载后原有内容会被临时隐藏，卸载后恢复）

基本语法

Section titled “基本语法”

mount（挂载）

  • 设备名：要挂载的存储设备（如 /dev/sda1）或网络资源（如 //192.168.1.100/share），可以是设备路径、UUID 或 LABEL
  • 挂载点：文件系统中的目录（如 /mnt/usb）
  • 若仅执行 mount 命令（不带参数），将显示当前所有已挂载的文件系统信息

umount（卸载）

  • 卸载时，既可以指定挂载点，也可以指定设备名

UUID

Section titled “UUID”

UUID（Universally Unique Identifier，通用唯一标识符）是一种由算法生成的 128 位数字，用于在全球范围内唯一标识信息。

在 Linux 系统中，UUID 常被用来标识硬盘分区等存储设备，其核心作用是提供一个持久且唯一的标识符，避免因设备名（如 /dev/sda1）变动导致的问题。设备名是动态分配的，可能因新增/移除设备、系统重启后检测顺序变化或更换接口而改变，而 UUID 是固定在文件系统中的唯一标识，不会随之变动。

UUID 特点

Section titled “UUID 特点”

(1) 唯一性

由规范定义的算法生成（如基于时间、硬件地址、随机数等），理论上在全球范围内不重复。

(2) 持久性

对于存储设备，UUID 会被写入文件系统的元数据中，除非主动修改，否则不会随系统重启、设备插拔、接口更换而改变。

(3) 格式固定

常用选项

Section titled “常用选项”

mount 选项

Section titled “mount 选项”
选项 说明
-t <文件系统类型> 指定要挂载的文件系统类型，若不指定，系统会自动检测
-o <挂载选项> 设置挂载参数（多个参数用逗号分隔），常见参数见下
-a 挂载 /etc/fstab 文件中所有未挂载的文件系统
-r 等价于 -o ro，只读挂载
-w 等价于 -o rw，读写挂载（默认）
-l 显示已挂载的文件系统，并附加卷标（Label）信息

常见 -o 挂载选项：

选项 说明
ro 只读挂载
rw 读写挂载（默认）
loop 挂载镜像文件（如 ISO）
noatime 不更新文件访问时间（提升性能）
remount 用新的挂载选项重新挂载已挂载的文件系统
defaults 使用默认参数（rw, suid, dev, exec, auto, nouser, async）

常见文件系统类型：

类型 说明
ext4 Linux 常见文件系统
vfat FAT32（兼容 U 盘/Windows）
ntfs Windows NTFS 分区
iso9660 光盘/ISO 镜像
nfs 网络文件系统（Unix/Linux 常用）
cifs Windows 共享文件系统（Samba）

umount 选项

Section titled “umount 选项”
选项 说明
-l 懒卸载（lazy unmount）：立即解除关联，延迟到所有进程不再使用后真正卸载
-f 强制卸载：即使文件系统处于忙碌状态也强制卸载（可能导致数据丢失，谨慎使用）
-r 若卸载失败，尝试以只读方式重新挂载文件系统（用于故障恢复）
