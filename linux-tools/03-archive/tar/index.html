tar

简介

Section titled “简介”

tar（Tape Archive）是 Linux 系统中用于文件归档（打包）和压缩的经典工具，可将多个文件或目录合并成一个归档文件，并支持与 gzip、bzip2、xz 等压缩算法结合生成压缩包。

基本语法

Section titled “基本语法”
  • 操作选项：决定 tar 做什么（创建、解包、列出…），是必选选项
  • 压缩选项：决定是否启用 gzip、bzip2、xz 等压缩
  • 辅助选项：控制 tar 行为
  • 文件名/目录：对于归档操作，用于指出需要归档的文件/目录；对于提取操作，用于指出需要提取的文件/目录，如果不指定默认提取全部

-f 后面必须紧跟归档文件名，且放在所有选项的最后

常用选项

Section titled “常用选项”

1. 操作选项（必选其一）

选项 说明
-c 创建新的归档文件（打包）
-x 从归档文件中提取文件（解压）
-t 列出归档文件中的内容（查看）
-r 向已有的归档文件中添加新文件（只能对未压缩的 .tar 用）
-A 向已有归档里追加另一个归档（只能对未压缩的 .tar 用）
-d 比较归档文件与实际文件的差异

2. 压缩选项

选项 说明
-z 通过 gzip 压缩/解压，对应文件扩展名 .tar.gz 或 .tgz
-j 通过 bzip2 压缩/解压，对应文件扩展名 .tar.bz2 或 .tbz
-J 通过 xz 压缩/解压，对应文件扩展名 .tar.xz
-I <压缩程序> 调用系统中安装的其他压缩工具来处理归档文件的压缩和解压

3. 辅助选项

选项 说明
-f <filename> 指定归档文件名，必须紧跟文件名
-C <dir> 切换目录，提取或打包时先切换到指定目录再处理，用法很多，见示例
-v 显示详细过程，列出处理的每个文件
-w 在每次操作前询问用户确认
-p 保留文件权限，提取时恢复原文件的权限和属性
-k 保留原文件，提取时不覆盖已存在的文件
--exclude=<GLOB> 排除文件/目录，不将匹配 GLOB 的文件加入归档
--exclude-from=FILE 从列表文件读取排除规则
--progress 显示进度条（与 -v 一起使用）
